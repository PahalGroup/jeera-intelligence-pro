# Jeera (Cumin) Live Intelligence Web Application & Pluggable Kirana Pulse Module

Real-time Indian commodity intelligence platform for Jeera (HS Code 090931).

## Features
- 1-Tap Unit Switcher (Maund 20kg, Bag 55kg, Quintal 100kg, Rs/kg, $/MT FOB)
- Live Weather Radar via Open-Meteo JSON API
- Durg, Chhattisgarh Wholesale Landed Calculator
- Pluggable `<KiranaSpicePulse />` widget and `/api/v1/kirana/jeera-pulse` endpoint
- Spices Board 25-Country Export Ledger & 20 Historical Case Studies
